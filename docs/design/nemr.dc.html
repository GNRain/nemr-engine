Start a session and it follows you

A session is a container with its own disk, running your agent and holding its whole conversation. Push it to the cloud encrypted, sit down at another machine, pull it back, and the agent picks up mid-thought.

This machine Runs the agent, holds the disk
Cloud Encrypted here before it leaves
Any other machine Pull it down, the history is intact

The same two marks appear on every session card, filled where the bytes actually are. Nothing about where a session lives is signalled by colour.
